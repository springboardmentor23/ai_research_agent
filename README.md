# AI Research Agent – Milestone 1

## Objective
Automate the retrieval of research papers using the Semantic Scholar API and
create a structured dataset for further analysis.

## Description
The base code provided by the mentor was used as a reference.
The project was expanded to include:
- User input handling
- Dataset creation
- Output persistence
- Proper project structure
